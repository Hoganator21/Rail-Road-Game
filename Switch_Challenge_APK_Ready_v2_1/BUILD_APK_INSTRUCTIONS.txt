HOW TO BUILD THE SIGNED / DEBUG APK IN ANDROID STUDIO OR CLI
==============================================================
This sandbox cannot compile a signed Android APK binary directly because the Android SDK/Gradle
build toolchain isn't installed here, so this ZIP provides the complete Android Studio / Gradle
project with your app bundled in `app/src/main/assets/www/`.

Option A — Android Studio (Easiest):
1. Extract `Switch_Challenge_Android_APK_Project.zip`.
2. Open the extracted folder in Android Studio.
3. Wait for Gradle sync to finish, then click Build -> Build Bundle(s) / APK(s) -> Build APK(s).
4. Your `.apk` file will appear in `app/build/outputs/apk/debug/app-debug.apk`.

Option B — Command Line (with Android SDK installed):
  ./gradlew assembleDebug
